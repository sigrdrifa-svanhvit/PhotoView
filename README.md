# PhotoView

zip / rar / 7z などの圧縮ファイル内やフォルダ内の画像を、**解凍せずに**透過的に閲覧できる Windows デスクトップ画像ビューアです。
Windows フォト風の操作で、複数画像をメモリ上にキャッシュして滑らかに送り戻しができます。

## 動作環境

- Windows 10 / 11
- .NET 10 デスクトップランタイム（SDK でビルドする場合は .NET 10 SDK）

## インストール（推奨）

配布用 MSI インストーラーを実行すると、以下が設定されます。

- アプリ本体（`%LOCALAPPDATA%\PhotoView\` にインストール）
- **画像ファイルの関連付け**（.png / .jpg / .jpeg / .webp / .bmp / .gif / .tif / .tiff → ダブルクリックで PhotoView が開く）
- **スタートメニューショートカット**
- **「送る」メニュー**（右クリックメニューの「送る」→ PhotoView）

※ **圧縮ファイル（zip / rar / 7z など）はデフォルトでは関連付けされません**。
   圧縮ファイルは右クリックメニューの **「送る」→ PhotoView** で開いてください。

### 上書きインストール / アップデート

MSI は同じ `UpgradeCode` を持つため、新しいバージョンの MSI を実行すると**自動的に上書きインストール**されます。
既存の設定（関連付け・「送る」）はそのまま引き継がれます。

### アンインストール

- Windows の「設定 → アプリ」または「コントロールパネル → プログラムと機能」から「PhotoView」をアンインストール
- アプリ本体・関連付け・「送る」ショートカットがすべて削除されます


## 使い方

### 開く方法
- **ドラッグ＆ドロップ**：ウィンドウにフォルダ・画像ファイル・圧縮ファイルをドロップ
- **Ctrl+O**：ファイル（画像 / zip / rar / 7z など）を開く
- **Ctrl+Shift+O**：フォルダを開く
- **コマンドライン**：`PhotoView.exe 開きたいパス`
- 起動時はプライマリディスプレイの中央にウィンドウが配置されます

### ナビゲーション
| 操作 | 動作 |
|------|------|
| **← / → キー** | 前 / 次の画像（2ページ表示では **2枚ずつ** 送り戻し） |
| 画面の **左 1/3 / 右 1/3 をクリック** | 前 / 次の画像（2ページ表示では **2枚ずつ**） |
| **Shift + ← / → キー** | 1枚ずつ送り戻し（2ページ表示では2枚のセットを1枚ずらす） |
| **Shift + クリック** | 同上（1枚ずつ） |
| **PgUp / PgDn** | 10 枚前 / 後 |
| **Home / End** | 先頭 / 末尾 |
| **Space / BackSpace** | 次 / 前 |
| サムネイルクリック | その画像へ移動 |
| サムネイル上でマウスホイール | サムネイルストリップを横スクロール |

※ 2ページ表示では、切り替えた時点の表示画像を起点に2枚ずつ送り戻します。

### 表示
- **P キー**：2ページ表示モードの切り替え（2枚を横に並べて表示し、1枚ずつ送り戻し）
- **S キー**：2ページ表示の左右入れ替え（デフォルトは「現在ページが右、次ページが左」）
- **Ctrl+L / Ctrl+R**：表示中の画像を左（反時計回り）/ 右（時計回り）に **90°回転**
- **マウスホイール**：拡大 / 縮小（カーソル位置基準）
- **ドラッグ**：ズーム中はパン
- **ダブルクリック**：フィット表示 ⇔ 100% 表示
- **0 キー**：ウィンドウにフィット（フィットは画像と表示領域の**制約になる側**（縦/横）に合わせてスケーリング）
- **+ / - キー**：拡大 / 縮小
- **F11**：全画面（ウィンドウ左上にカーソルを置くと**全画面⇔通常トグルボタン**が表示され、クリックで切替。全画面中は右上に**閉じるボタン**が表示され、クリックで終了）
- **画面中央クリック / Esc**：UI バーの表示固定 / 非表示
- **上部タイトルバー・下部サムネイル**は、マウスカーソルがその領域にあるときだけ表示され、領域外では自動的に隠れます
- **右クリック**：コンテキストメニュー

### 簡易画像編集
右クリックメニューの **「編集」** から、現在の画像を編集ダイアログで編集できます。元ファイルは変更されず、編集結果は**「名前を付けて保存」**で別ファイルに保存します（アーカイブ内など元に書き込めない画像でも安全に編集できます）。

- **リサイズ**：「任意リサイズ」を押すと画像上にフレームが表示され、枠の辺・角をドラッグしてサイズを変更できます。「縦横比を保つ」をOnにすると縦横比固定で伸縮し、「リサイズを適用」で確定します
- **回転 / 反転**：左90° / 右90° 回転、左右・上下反転、任意角度（度）での回転（余白は透明）。「画像をドラッグ＆ハンドルで任意回転」を有効にすると、**ブラシホイールで拡大縮小**しながら**回転ハンドル（○）を掴んで任意角度に回転**でき、「画像回転を適用」で確定します
- **トリミング**：画像上でドラッグ選択 →「選択範囲でトリミング」。選択枠は**ハンドルで回転**でき、回転を含む正立の矩形領域を抜き出し、選択四角形の外側は透明化されます
- **カラー変更**：明るさ / コントラスト / 彩度 / **色相**（±180°）スライダー（ライブプレビュー）、グレースケール / セピア / 反転
- **局所モザイク化**：領域選択 → モザイク強さ設定 →「選択範囲にモザイク」。回転した選択範囲にも適用されます
- **ぼかし（ガウシアン）**：強さ（σ）を設定 →「ガウシアンブラー（選択 or 全体）」。範囲選択があればその領域のみ、なければ全体へ適用
- **保存形式変更**：PNG / JPEG / GIF / BMP / TIFF / WebP
- **超解像**：Real-ESRGAN（ONNX Runtime・4倍・アニメ向けモデル）で高解像度化。CPU では1枚数秒のため明示実行。モデル（約5MB）と onnxruntime（約11MB）を同梱
  - **超解像を適用（4倍・AI）**：4倍に拡大
  - **同サイズ超解像（画質向上・寸法不変）**：4倍へ超解像後にバイキュービックで元サイズへ縮小。範囲選択がある場合は**その選択範囲のみ**処理
- 元に戻す（直前）／すべて破棄（元画像へ）

プレビューは**マウスホイールで拡大縮小**でき、**中ボタン（ホイール押し込み）のドラッグで表示位置を移動**できます（編集結果を拡大して細部を確認するのに便利）。

## 対応形式

- **画像**：png / jpg / jpeg / webp / bmp / gif / tif / tiff
  - webp は SkiaSharp でデコード（WPF 標準コードックに非依存）。保存も SkiaSharp で WebP エンコード
  - 高DPI（72/144dpi など）画像もピクセル単位で正確に表示
  - **アニメーション GIF** は再生対応（巨大な GIF はメモリ保護のため先頭フレームのみ）
  - **複数ページ TIFF**（.tif/.tiff）は1ページずつに分割して表示
- **圧縮ファイル**：zip / rar / 7z / tar / gz / bz2 / xz / cab / tgz / tbz / txz / cbz / cbr / cb7
  - SharpCompress で開けなかった場合は .NET 標準 ZIP で自動再試行
- **EPUB**：`.epub`（ZIP コンテナ。`container.xml` / OPF の **spine 順**でページ画像を表示。各ページが XHTML の場合は最初の `<img>` を画像として扱い、構造が読めない場合は通常の ZIP として画像一覧表示にフォールバック）
- **PDF**：`.pdf`（Windows 標準の PDF エンジン＝Windows.Data.Pdf で各ページをラスタライズ。追加 DLL 不要で Win10/11 で動作）
- ファイル名は**自然順**（img2, img10, img20 の順）でソート（EPUB/PDF はページ順を優先）

## 設計

- `Models/`
  - `MediaCollection` / `MediaItem`：フォルダと圧縮アーカイブを統一的に扱う抽象層
  - `NaturalStringComparer`：自然順ソート（反対称性・推移性をテストで検証）
- `Services/`
  - `ImageDecoder`：Stream → フリーズ済み `BitmapSource`（webp フォールバック込み）
  - `ImageCache`：デコード済み画像の LRU インメモリキャッシュ＋周辺プリフェッチ
  - `ThumbnailCache`：サムネイルストリップ用の小サイズ画像キャッシュ
  - `PdfSource` / `PdfPageItem`：Windows.Data.Pdf（WinRT）による PDF ページのラスタライズ
  - `TiffPageSplitter` / `TiffFrameItem`：複数ページ TIFF の1ページ単位への展開
- `PhotoView.Tests/`：`NaturalStringComparer` の不変条件（反射性・反対称性・推移性）を検証するコンソールテスト

### メモリキャッシュによる滑らかな送り戻し

現在の画像の周辺（±14 枚）をバックグラウンドで**プリフェッチ**し、デコード済み `BitmapSource` を LRU キャッシュ（最大 24 枚 / 約 600 MB）に保持します。左右キーでの移動時はデコードを待たずにキャッシュから即時表示されます。アーカイブ（特に 7z/RAR のソリッド形式）は並行読み取り不可のため、読み取りロックで直列化しています。
